# SaladCloudImdsError

An API error. The `code` and `type` uniquely identify the type of the error. The `code` is a short value that may be used for programmatic error handling. The `type` is an absolute URL that may be resolved for more detailed information. Refer to the [SaladCloud IMDS reference](https://leaf.salad.com/l/saladcloud-imds-errors) for a list of the expected `code` and `type` values. Also, note that all properties are optional. Clients should implement robust error handling to account for unexpected errors.

**Properties**

| Name     | Type                      | Required | Description                                                                                                                                                                                                                                                                                                                                              |
| :------- | :------------------------ | :------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| code     | String                    | ❌       | The error code that identifies the error type. This is a short value that may be used for programmatic error handling.                                                                                                                                                                                                                                   |
| detail   | String                    | ❌       | The human-readable explanation specific to this occurrence of the error.                                                                                                                                                                                                                                                                                 |
| errors   | Map<String, List<String>> | ❌       | The contextualized map of human-readable explanations specific to this occurrence of the error. This is often used to provide property-specific errors, such as validation errors. In these scenarios, the key is the property name and the value is an array of human-readable explanations specific to this property and this occurrence of the error. |
| instance | String                    | ❌       | The URI reference that identifies the specific occurrence of the error.                                                                                                                                                                                                                                                                                  |
| status   | Long                      | ❌       | The HTTP status code generated by the origin server for this occurrence of the error.                                                                                                                                                                                                                                                                    |
| title    | String                    | ❌       | The short, human-readable summary of the error type.                                                                                                                                                                                                                                                                                                     |
| type     | String                    | ❌       | The URI reference that identifies the error type.                                                                                                                                                                                                                                                                                                        |
